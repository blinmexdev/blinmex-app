# 🛡️ Blinmex | Plataforma Web de Administración & Backoffice

Plataforma web de gestión operativa, comercial, control de clientes y unidades blindadas para **Blinmex**.

---

### 🛠️ Arquitectura & Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript (ES6+ Vanilla / Fetch API)
- **UI Framework:** Bootstrap 5.3 (Basado en UI Kit de Sneat)
- **Backend API:** Consumo de servicios RESTful (`blinmex-backend`)
- **Iconos & Componentes:** Boxicons, ApexCharts, Perfect Scrollbar

---

### 📁 Estructura del Proyecto

- `html/`: Módulos y vistas principales de la aplicación
- `assets/`: Hojas de estilo CSS, imágenes del sistema, scripts JS y librerías
- `login.html`: Pantalla de acceso y autenticación
- `index.html`: Dashboard principal y panel de métricas

---

### 🚀 Flujo de Trabajo Local & Control de Versiones

1. Clonar el repositorio localmente:
   `git clone https://github.com/blinmexdev/blinmex-app.git`
2. Abrir el proyecto en Visual Studio Code.
3. Realizar cambios en la maquetación o integración con la API.
4. Confirmar y publicar cambios:
   `git add .`
   `git commit -m "feat: módulo de cotizaciones maquetado"`
   `git push origin main`
